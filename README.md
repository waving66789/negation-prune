# negation-prune

剪掉你否定的东西：移除被否定概念在工程文件与记忆中的痕迹，一并剪除矛盾、过期、
冗余的规则，反推真实意图并持久化。Prune what you negated.

规则库只保留"当前可执行且未被否定"的正面陈述。被否定的、过期的、矛盾的、重复的条目
要么删除要么改写为正面；拿不准的进待定。"确定正确"不是落账标准——"当前用户确认"才是；
**剪掉的是能识别的确定烂枝，不追求"所有"**。排除（"不要 X"）只是内部判定锚点，落盘内容
永远是正面陈述，被否定的 X 本身不进任何持久化文件；功能性禁则（改写成正面会失真、但按
原样可执行的禁止，如"不用破折号"）作为第三类显式保留并标注理由。

文件里否定句只存正面陈述——否定句留着，只会让"别想大象"越描越黑。

## 这是什么

一个标准 skill：一份 `SKILL.md`（自然语言工作流）。无代码、无插件、无配套文件，
全 harness 通用（opencode / Claude Code / Codex / Cursor / 任何支持 SKILL.md 的 agent）。

| 文件 | 作用 |
|---|---|
| `SKILL.md` | 全部逻辑：两种入口（用户否定 / 扫描发现）→ 剪枝 → 意图反推 → 安全线 |

**账本不随 skill 交付。** 负偏好账本（跨会话记住你真正要的偏好）由你在自己的
工作空间里用指令或自然语言创建（如"建个账本记我的偏好"），默认
`negation-ledger.md` 放项目根，位置你定。

## 安装

### 一键（推荐）

```bash
npx skills add <github-user>/negation-prune
```

### 手动

把 `SKILL.md` 复制成 `<对应目录>/skills/negation-prune/SKILL.md`：

| Harness | 位置 |
|---|---|
| opencode | `.opencode/skills/` 或 `~/.config/opencode/skills/` |
| Claude Code | `.claude/skills/` 或 `~/.claude/skills/` |
| 通用 agent | `.agents/skills/` 或 `~/.agents/skills/` |

装完即用，没有其他配置文件要放。

## 怎么触发

直接用自然语言，agent 按 `SKILL.md` 的加载条件自动判断：

- **剪枝（用户否定）**：「删除 X」「去掉 X」「我不需要 X」「别再用 X」/ "remove X" / "stop using X"
- **剪枝（扫描发现）**：「体检规则」「清理记忆」「瘦身」/ "audit my rules" / "prune memory"

边界写死在 SKILL.md 里：只对**真正下达的指令**生效；谈论"否定"这个概念本身、
或句子里顺带出现"不要"字样，不触发。

## 行为承诺（安全线）

1. Iron Law：无清单不删除；有清单直接执行，事后报告可撤销
2. 命中升级条件（全局规则/多文件分散/高危动作/低置信/非 git）时先确认再动手
3. 文件与账本只写正面陈述，否定原话与被否定概念永不落盘
4. 意图反推走置信度门控：高置信执行+声明，低置信出选项候选
5. 扫不到的区域如实标注，不假装扫过

## 换 harness 要改什么

`SKILL.md` 顶部「路径约定」里两个变量：`LEDGER`（账本路径，默认项目根 `negation-ledger.md`）
和 `GLOBAL`（全局配置目录，opencode `~/.config/opencode/`、Claude Code `~/.claude/`）。
其余路径按各 harness 原生规则发现。账本是纯正面偏好行，跨 harness 复制即用。

## 示例

### A 模式：剪枝事后报告（真实冒烟测试记录）

测试场景：短篇设定"复印店"。用户先写了文风契约（`工作文本.md`），其中一条是
"**数字**：能用数字的地方一律用数字，尤其金额、时间、剂量、度数。"
正文（`复印店.md`）按此写出，全文散布具体数值：137 元一分钟、0314-2-47-1985-0、
19 分 24 秒、N-04、找零 260。

用户随后否定："正文里的量级不要靠具体数字，用相对物和感官量词承担。"

按 A 流程执行：

| # | 文件:行号 | 当前内容 | 处置 |
|---|----------|---------|---------|
| 1 | 工作文本.md:13 | 数字：能用数字的地方一律用数字… | 改写为正面陈述"量的表达：一切量级由相对物和感官量词承担…" |
| 2 | 复印店.md:5 | 我站了大概二十秒 | 改写为"我站了很久" |
| 3 | 复印店.md:11 | 一百三十七一分钟 | 改写为"看带子多长"（价格由店员口头报，不写进正文） |
| 4 | 复印店.md:17 | 0314-2-47-1985-0 | 改写为"写着一行字，横着排，笔画挤在一起" |
| 5 | 复印店.md:21 | 十九分二十四秒／两千七百四 | 改写为"带子不长。走到底会自己停" |
| 6 | 复印店.md:23 | 三千…一张二十的，两张一百… | 改写为"我付了钱。他找了零给我，硬币搁在柜台上，响" |
| 7 | 复印店.md:25 | 刻着编号，N-04 | 改写为"侧面用刀刻着几个字" |
| 8 | 复印店.md:31-37 | 第一分钟/第二分钟/第三分钟/第四分钟/第五分钟 | 改写为"开头/再往后/楼下有摩托车发动" |
| 9 | 复印店.md:43 | 整个十九分钟里 | 改写为"整个带子里" |
| 10 | 复印店.md:49-51 | 第十一分零七秒/第十一分五十二秒 | 改写为"底噪的形状变了一下/隔开一小段" |

账本 +1：`2026-09-29 | 叙事写作 | 正文里的量级一律由相对物和感官量词承担，
金额、时间点、编号、计数这些具体数值只留在正文之外的大纲和记录中`

结果见 `prove/` 目录：`工作文本.md → 工作文本_v2.md`（规则改写前后），
`复印店.md → 复印店_v2.md`（正文改写前后）。

### B 模式：体检报告（同一文件）

B2① 扫 `工作文本_v2.md`，命中第 11 行禁则段：

> 不用"仿佛""似乎""一丝""淡淡""莫名""静静地""缓缓地""空气仿佛凝固"这类词。
> 不用破折号。不用感叹号。不用三连排比。不在结尾总结主题。

判定：**功能性禁则第三类**——"不用破折号/不用感叹号"改写成正面（"对白只用句号"
"句末不用标点强调"）会失真且不可验证，按原样可执行 → 保留原句，报告注明
"保留否定句 + 理由：功能性禁则，正面化后语义漂移"。
"不用仿佛/似乎/这类词"可精确改写为"比喻落在可验证的实物上，不用感受类模糊副词"
→ 归第一类，候选改写。
